# 魔物蛋

一个照万代的电子宠物「拓麻歌子」做的养成游戏: 在剑与魔法的奇幻世界里, 从一颗蛋开始养魔物。画面是带颜色的像素点, 竖着拿, 打算手机和平板都能玩 (现在先在电脑上试)。

作者的另外几个游戏: [《废土之旅》](https://github.com/aizhang453-hash/wasteland-trail) (致敬《俄勒冈之旅》的中文文字冒险游戏)、
[《最后的废土》](https://github.com/aizhang453-hash/the-last-wasteland) (致敬《辐射》一二代的角色扮演游戏)、
[《血脉与王冠》](https://github.com/aizhang453-hash/bloodline-and-crown) (致敬《十字军之王》的中世纪家族策略游戏)。

## 打算怎么做

- 最后要有很多玩法, 但一版一版加。**第一版先做 1996 年第一代原版的玩法** (再加一个图鉴)
- 以后再加: 小游戏赚钱、商店、换衣服布置房间、出门、不同的环境长成不同的魔物、寄养、训练和比赛、结婚生下一代、节日活动……
- 用 [Godot](https://godotengine.org/) 游戏引擎做 (免费、开源)

## 现在能玩什么 (v0.1)

- **跟着真实的时间走**: 一天长一岁。关掉游戏它也照样过日子, 下次打开一下子算到现在
- **照顾它**: 喂饭 (饱) 或零食 (开心, 但会胖)、玩猜左右的小游戏、开关灯、吃药、打扫便便、管教、看状态 (饿、开心、管教、岁数、体重)
- **它会叫你**: 饿了、不开心、睡着了没关灯、无理取闹的时候, 「呼叫」灯会闪。不及时照顾算一次「照顾失误」
- **长大**: 蛋 → 宝宝 → 小孩 → 少年 (2 种) → 成年 (6 种, 还有 1 种隐藏的, 只有「原版严格」养得出来)。照顾失误多少、管教得好不好, 决定长成哪一种
- **两种难度** (开局选):
  - 放宽 (推荐): 心掉得慢一半, 它叫你以后 2 小时没理才算失误, 失误多了也不会死, 只要别一整天不管它。隔几个小时看一次就行
  - 原版严格 (挑战): 跟原版一样, 它叫你以后 15 分钟没理就算失误 (不是要每 15 分钟看一次), 成年以后失误 5 次会死。最好每小时看一次
- **托人照看** (学现代拓麻歌子的暂停 / 照看模式): 上学、上班的时候托给别人, 照看的人会喂、哄、打扫、治病、关灯, 不叫你、不算失误, 它照样长大。每天最多 10 小时
- **三种结局**: 没照顾好会死; 成年后它会说想出去闯荡, 放它走就离开; 留下来的会一直陪你, 最后老死
- **图鉴**: 养出来的种类都记下来

## 怎么玩

要先装好 [Godot 4.7](https://godotengine.org/download) (免费)。然后二选一:

- 打开 Godot, 点「导入」, 选游戏文件夹里的 `project.godot`, 再点右上角的 ▶ (或者按 F5)
- 或者在 Mac 的终端里输入 (Windows 上把前面换成 Godot 程序的位置):

```
/Applications/Godot.app/Contents/MacOS/Godot --path ~/game/monster-pet
```

用鼠标 (手机上用手指) 点下面的 8 个按钮。从 Godot 里打开的是「调试版」, 「更多」里有快进 10 分钟、1 小时、8 小时的按钮, 试玩的时候不用真的等。
