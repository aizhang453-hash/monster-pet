# 魔物蛋

一个照万代的电子宠物「拓麻歌子」做的养成游戏: 在剑与魔法的奇幻世界里, 从一颗蛋开始养魔物。画面是带颜色的像素点, 竖着拿, 打算手机和平板都能玩 (现在先在电脑上试)。

作者的另外几个游戏: [《废土之旅》](https://github.com/aizhang453-hash/wasteland-trail) (致敬《俄勒冈之旅》的中文文字冒险游戏)、
[《最后的废土》](https://github.com/aizhang453-hash/the-last-wasteland) (致敬《辐射》一二代的角色扮演游戏)、
[《血脉与王冠》](https://github.com/aizhang453-hash/bloodline-and-crown) (致敬《十字军之王》的中世纪家族策略游戏)。

## 打算怎么做

- 最后要有很多玩法, 但一版一版加。**第一版先做 1996 年第一代原版的玩法** (再加一个图鉴); 第二版加了魔晶、商店、装扮和更多小游戏; 第三版加了住的地方、出门和旅馆; 第四版加了训练和比赛; 第五版加了上学和工作; 第六版加了更多小游戏、节日、纪念品、洗澡; 第七版加了结婚和下一代; 第八版加了美食街、自己散步、捣蛋精、小宠物、性格; 第九版加了混血魔物和算命的; 第十版加了老年和家谱; 第十一版加了一家人住在一起和双胞胎
- 以后再加: 乐园等级、一个地方住好几只、派对、才艺……
- 用 [Godot](https://godotengine.org/) 游戏引擎做 (免费、开源)

## 现在能玩什么 (v0.11)

- **跟着真实的时间走**: 一天长一岁。关掉游戏它也照样过日子, 下次打开一下子算到现在
- **照顾它**: 喂饭 (饱) 或零食 (开心, 但会胖)、玩小游戏、开关灯、吃药、打扫便便、洗澡、管教、看状态 (第一页是名片: 名字、第几代、岁数、体重、在哪、魔晶; 再按看饿、开心、干净、管教, 还有本事)
- **它会叫你**: 饿了、不开心、睡着了没关灯、无理取闹的时候, 「呼叫」灯会闪。不及时照顾算一次「照顾失误」
- **长大**: 蛋 → 宝宝 → 小孩 → 少年 (2 种) → 成年 (6 种, 还有 1 种隐藏的, 只有「原版严格」养得出来)。照顾失误多少、管教得好不好, 决定长成哪一种
- **两种难度** (开局选):
  - 放宽 (推荐): 心掉得慢一半, 它叫你以后 2 小时没理才算失误, 失误多了也不会死, 只要别一整天不管它。隔几个小时看一次就行
  - 原版严格 (挑战): 跟原版一样, 它叫你以后 15 分钟没理就算失误 (不是要每 15 分钟看一次), 成年以后失误 5 次会死。最好每小时看一次
- **托人照看** (学现代拓麻歌子的暂停 / 照看模式): 上学、上班的时候托给别人, 照看的人会喂、哄、打扫、治病、关灯, 不叫你、不算失误, 它照样长大。每天最多 10 小时
- **几种结局**: 没照顾好会死; 成年后它会说想出去闯荡, 放它走就离开; 结婚生下一颗蛋 (第七版); 留下来的会一直陪你, 最后老死 (也会留下一颗蛋)
- **图鉴**: 养出来的种类都记下来
- **魔晶和商店** (第二版): 玩小游戏赚魔晶, 在商店买好吃的、玩具、衣服配饰、房间布置。饭、零食、药一直免费
- **装扮** (第二版): 戴帽子、领结围巾, 换墙纸地毯、摆家具。只是好看
- **13 个小游戏** (第二版 4 个, 第六版又加 9 个): 宝宝 猜左右、猜数字、跳绳、爬高; 小孩起 接果子、拔河、模仿; 少年起 跳石头、举旗、赛跑;
  成年起 记颜色、跳舞、做汉堡
- **三个住的地方** (第三版): 草原、湖泊、天空岛各有一整套魔物, 一共 29 种; 养大一只成年就打开一个新地方
- **出门** (第三版): 小孩起能去公园、森林、湖边、夜市逛 (有的要先解锁); 还能花魔晶住旅馆
- **训练和比赛** (第四版): 练力气、速度、防御; 少年起去比赛, 自动对打, 五个级别, 赢了拿奖杯和魔晶
- **开始界面** (第四版): 打开游戏先看到「魔物蛋」和你的魔物, 按「开始」或「继续养」
- **上学和工作** (第五版): 小孩和少年上数学课、美术课、品德课 (答题); 成年找工作 (7 种)、上班赚魔晶
- **夸它、摸摸它、收到信** (第五版): 做了好事夸它; 用手指点它摸摸它; 信箱里有成绩单、工作介绍、离开的魔物寄回来的信
- **节日** (第六版): 新年、春节、儿童节、中秋、万圣节、圣诞节那天, 屏幕上有节日装饰, 打开游戏收到礼物和纪念品, 商店有节日的吃的
- **纪念品** (第六版): 出门有时带回那个地方的纪念品, 过节送节日的, 一共 11 种
- **洗澡** (第六版): 它会慢慢变脏, 没有便便的时候按「打扫」给它洗澡
- **结婚和下一代** (第七版): 成年以后媒人上门介绍对象, 结婚生下一颗蛋; 孩子长成哪一种看照顾, 颜色和头上的小特征从爸妈那里遗传;
  爸妈搬去爸妈家, 忙的时候能把孩子送过去。留到老的魔物走的时候也会留下一颗蛋
- **每天的小事** (第八版): 去美食街吃好吃的; 它会自己溜出去散步, 回来带点小东西; 有捣蛋精来捣乱就点它一下;
  在商店领养小宠物陪着它; 长成小孩的时候帮它选性格
- **混血魔物和算命的** (第九版): 特别有缘的两种结婚, 孩子照顾得好会长成没见过的混血魔物 (6 种); 混血再跟特定的一位结婚,
  生下闪闪发光的大奖蛋 (两族, 各有自己的长法)。结婚前能找算命的看看宝宝长什么样, 「更多 → 算命屋」随时能配配看。
  孩子身上还会遗传小翅膀、尾巴这些 (少年起长出来)。不想等媒人的话, 可以去约会广场约会求婚, 或者跟朋友慢慢变熟、带戒指求婚;
  过节那天还有节日嘉宾。每个地方的小孩也长得不一样 (搬家住满一小时就变样)
- **老年和家谱** (第十版): 成年好几天还没结婚就老了, 戴老花镜、拄拐杖, 媒人不来、也不能结婚; 老了可以让它去当媒人, 以后来你家做媒。
  「更多 → 家谱」看一代代的家族, 还能拍全家福
- **一家人住在一起和双胞胎** (第十一版): 结婚的两口子、放走的孩子会住到它们长大的地方, 出门 → 看看家人 就能去看;
  结婚生的蛋偶尔是双胞胎, 两只一起照顾, 结婚时挑一只, 另一只住到那个地方

## 怎么玩

要先装好 [Godot 4.7](https://godotengine.org/download) (免费)。然后二选一:

- 打开 Godot, 点「导入」, 选游戏文件夹里的 `project.godot`, 再点右上角的 ▶ (或者按 F5)
- 或者在 Mac 的终端里输入 (Windows 上把前面换成 Godot 程序的位置):

```
/Applications/Godot.app/Contents/MacOS/Godot --path ~/game/monster-pet
```

用鼠标 (手机上用手指) 点下面的 8 个按钮。从 Godot 里打开的是「调试版」, 「更多」里有快进 10 分钟、1 小时、8 小时的按钮, 试玩的时候不用真的等。

## 放到 iPhone / iPad 上 (第四版开始准备)

能导出成 Xcode 项目了, 但要在 Mac 上装了 Xcode 才能装到 iPhone / iPad 上:

1. 在 Mac 的 App Store 搜「Xcode」安装 (免费, 十几 GB)。装好打开一次, 同意许可; 它问要不要装 iOS 的东西, 就选装
2. Xcode 菜单 → Settings → Accounts → 左下角「+」→ Apple ID, 用你的 Apple ID 登录 (免费的就行)
3. 导出 Xcode 项目: 在 Mac 的终端里输入 (Claude 也可以帮你做)

```
/Applications/Godot.app/Contents/MacOS/Godot --headless --path ~/game/monster-pet --export-debug "iOS" export/ios/MonsterEgg.ipa
```

4. 用数据线把 iPhone / iPad 连到 Mac, 在 Xcode 里打开 `export/ios/MonsterEgg.xcodeproj`
5. 左边点最上面的「MonsterEgg」→ 中间上面的「Signing & Capabilities」→ Team 选你自己的 (Personal Team)
6. Xcode 最上面选你的 iPhone / iPad, 按 ▶
7. 第一次装: iPhone / iPad 上「设置 → 隐私与安全性 → 开发者模式」打开 (会重启);
   再到「设置 → 通用 → VPN 与设备管理」里信任你的 Apple ID

免费的 Apple ID 装上去的 App, 7 天后会打不开, 再连上 Mac 按一次 ▶ 就好; 付费的苹果开发者账号 (每年 99 美元) 一年有效。
